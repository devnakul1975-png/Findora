Key Project Highlights

  • ✪
    Jointly Engineered Findora from Scratch: Dev Khandelwal and Ayush Jha co-led and designed the complete end-to-end architecture, UX wireframes, client logic, and database schemas.
  • ✪
    Dual-Engine AI Matching: Integrated Google Gemini 3.8 Flash for semantic similarity matching between lost descriptions and found items, paired with offline heuristic fallback.

  • ✪
    Rigorous Automated Testing: Passed 19/19 automated test suites verifying token authorization, role-based access control, and report deduplication.

    Serverless Cloud Deployment: Successfully deployed on Vercel with high-speed global edge distribution (<20ms load latency).
